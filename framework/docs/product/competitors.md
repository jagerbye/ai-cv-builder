# competitors.md — who else solves this problem

> **What this file is:** sourced competitor research from discovery. Every
> claim carries a URL and an as-of date, or the explicit mark
> **(assumption, unverified)** — rules/research-integrity.md. Feeds the
> feature map: what to improve, what to differentiate on.

> **Not used by this project.** Discovery was skipped on purpose: the owner
> supplied a written brief, not a raw idea (see ADR-008 in
> `framework/docs/decisions.md`). This file is left as the framework's
> template so it is clear it was never started, not abandoned halfway.
> The only live product doc here is `assumptions.md`.


Format — one block per competitor:

```
## <Name>  (checked YYYY-MM-DD)
- What it is: <one line> [source]
- Strong: <what they do well> [source]
- Weak: <what users complain about / gaps> [source or (assumption, unverified)]
- Pricing: <model + numbers> [source]
- What we take: improve <X> / avoid <Y> / ignore <Z>
```
