# tests/ — cross-cutting suites

> **What this folder is:** contract tests (`contract/`) and integration/e2e
> suites (`e2e/`) per `framework/docs/testing-strategy.md`. Unit tests do NOT live
> here — they sit next to the code they test. Contract tests are derived
> from `framework/docs/api-contracts.md` (one suite per C-NNN, error cases included);
> e2e suites are derived from spec acceptance criteria (one per F-NNN).
